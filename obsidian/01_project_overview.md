# Огляд Проєкту

## Бізнес-ідея
Комплексна екосистема для авто-бізнесу, що об'єднує три напрямки:
- **СТО** — сервісне обслуговування
- **Шиномонтаж** — сезонне обслуговування
- **Каталог авто** — продаж та викуп транспортних засобів

## Три Головні Компоненти

### 1. Сайт (Фасад)
Клієнтська платформа з акцентом на UX:
- Швидкий гостьовий флоу (без реєстрації)
- Ненав'язливий "Гараж" (збереження авто клієнта)
- Тіньові акаунти (конвертація гостя → клієнт)

### 2. CRM (Управлінська база)
Бек-офіс для операцій:
- Обробка лідів
- Наряди-замовлення
- Зміна статусів авто

### 3. QA/Security Bot
Автономний скрипт-сторож:
- Security вразливості
- API endpoints health-check
- Навантажувальне тестування

## Центральна Сутність: `Vehicle`
Авто є ядром системи і може змінювати статус власності:
```
Клієнт ↔ Компанія
```
Це ключова бізнес-логіка, навколо якої будується вся архітектура.

## Архітектурний Принцип
Спочатку — дискусія. Потім — специфікація. Тільки після затвердження — код.
