## ADDED Requirements

### Requirement: Vehicle завжди створюється при booking, поля є nullable
При кожному booking система SHALL створювати запис `Vehicle` в БД. Поля `plate`, `vin`, `make`, `model`, `year`, `color` є nullable — заповнюються адміністратором через CRM або клієнтом через Гараж пізніше.

#### Scenario: Booking без деталей авто
- **WHEN** гість надсилає форму запису без жодних даних про авто
- **THEN** система створює `Vehicle { id: uuid, plate: null, make: null, ... }` та прив'язує до booking і до user через `user_vehicles`

#### Scenario: Booking з частковими деталями авто
- **WHEN** гість надсилає форму з `plate: "AA1234BB"` та `make: "Toyota"`, але без VIN
- **THEN** система створює `Vehicle { plate: "AA1234BB", make: "Toyota", vin: null, ... }`

### Requirement: Клієнт може додати авто до Гаражу вручну
Автентифікований користувач SHALL мати можливість додати новий Vehicle до свого Гаражу безпосередньо з інтерфейсу, не через форму запису. Мінімально необхідне поле — держномер.

#### Scenario: Ручне додавання авто
- **WHEN** авторизований користувач надсилає `POST /vehicles` з `{ plate: "BC5678CD" }`
- **THEN** система створює Vehicle, додає запис до `user_vehicles`, авто з'являється в Гаражі

#### Scenario: Спроба додати авто без жодного поля
- **WHEN** користувач надсилає `POST /vehicles` з порожнім тілом
- **THEN** API повертає `400 Bad Request` з повідомленням що хоча б `plate` є обов'язковим при ручному додаванні

### Requirement: Клієнт може приховати авто в Гаражі
Автентифікований користувач SHALL мати можливість приховати авто зі свого Гаражу (наприклад, після продажу компанії). Авто та його сервісна історія зберігаються в БД, але не відображаються за замовчуванням.

#### Scenario: Приховання авто
- **WHEN** користувач натискає "Приховати" для конкретного авто в Гаражі
- **THEN** `user_vehicles.is_hidden` встановлюється в `true`, авто зникає з основного списку Гаражу

#### Scenario: Перегляд прихованих авто
- **WHEN** користувач відкриває розділ "Архів" або "Приховані" у Гаражі
- **THEN** система повертає vehicles де `user_vehicles.is_hidden = true` для цього користувача
